# 导入 SubLoom 视频生词

在 SubLoom 的本地生词本选择「导出到 Transportal」，然后在 Transportal 打开「设置 → 生词收藏 → 导入 SubLoom」。选择生成的 `subloom-transportal-v1.json`，而不是 SubLoom 的普通 JSON 备份文件。

- 当前支持英文用法；保留释义、音标、词性、字幕原句、已有译文、来源视频和时间点。YouTube 链接可回到对应时间；其他站点的跳转取决于播放器。
- 导入采用本地事务，重试不会创建相同用法，已保存的释义和第一份上下文不会被覆盖。任何无效记录都会取消整批导入；文件上限为 2,000 条、8 MiB。
- 两个应用不会自动同步，不启动任何本地服务器，也不会共享凭据。只有选择文件才会导入，只有点击来源视频才会打开浏览器。
