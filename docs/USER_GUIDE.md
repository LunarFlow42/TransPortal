# TransPortal 用户操作文档

轻量传送门（TransPortal）是一款开源桌面翻译与词典协同工作台。它常驻托盘，通过全局快捷键随时捕获你在任意软件中选中的文本，并自动判断是"单词"还是"句子"，分别以**深度词卡**或**幽灵伴读气泡**呈现。

---

## 1. 运行环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11（原生划词）、macOS / Linux（仅剪贴板降级） |
| 网络 | 使用在线翻译 / AI 增强时需要联网 |
| 可选 | 本地 Anki + AnkiConnect 插件（用于生词同步） |

> 离线词典查询、音标释义、词卡形变等核心交互无需联网。

---

## 2. 启动与退出

1. 启动 TransPortal 后，主界面（幽灵气泡窗口）会出现在屏幕中央。
2. 关闭窗口不会退出程序，应用会**最小化到系统托盘**继续常驻。
3. 退出方式：
   - 右键 / 左键点击托盘图标 → `Quit TransPortal`；
   - 或在气泡右上角菜单中选择退出（依版本而定）。

托盘菜单项：

- `Show TransPortal`：显示气泡窗口
- `Hide to Tray`：隐藏到托盘
- `Quit TransPortal`：完全退出

## 3. 核心操作：全局划词

### 3.1 默认快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Alt + T` | 捕获当前选中文本并唤醒窗口 |
| `Ctrl + C + C` | Windows 上在 0.5 秒内按两次 C，翻译本次复制的文字 |
| `Alt + Shift + T` | Windows 框选屏幕文字，识别后复制并展示文字（纯 OCR） |
| `Alt + Shift + S` | Windows 框选屏幕文字，在图片原文字位置显示译文 |

> 所有快捷键可在设置中自定义。截图不再调用 Windows 截图工具：按下快捷键后桌面立即冻结并出现框选层，松开鼠标即识别。

启动时若发现取词键或截图键注册失败，浮层会列出冲突键位。关闭占用它的软件后点击 **重新检测**；也可在设置的 **Global Shortcut** 分区查看状态或更换键位。注册失败会保留原有可用键位，不会把失败的选择保存为当前值。

### 3.2 使用步骤

1. 在任意应用（浏览器、PDF 阅读器、Office、IDE 等）中选中一段文字。
2. 按下 `Alt + T`。
3. TransPortal 自动执行：
   - 优先通过 **UI Automation** 读取焦点控件的选区；
   - 若目标控件不支持，则向原窗口发送复制指令，确认剪贴板更新后读取；复制失败时提示重试。
4. 窗口在鼠标位置附近弹出，并自动分流：

| 选中内容 | 呈现方式 |
| --- | --- |
| 单个单词 / 短词组（≤ 2 词且无句末标点） | **深度词卡（Word Card）** |
| 句子 / 段落 | **幽灵伴读气泡（Ghost Bubble）** |

> 自动分流基于本地毫秒级启发式判断，词数、字符数与标点共同决定。

也可按住 `Ctrl`，在 0.5 秒内按两次 `C`；两次复制之间松开 Ctrl 也可以。长按 C 的键盘连发不会触发翻译。开关位于设置的 **Global Shortcut → Ctrl+C+C 翻译**，关闭后仍可正常复制。

要替换其他软件输入框中的原文，取词后点击结果卡的 **替换选中文字**。程序会回到原窗口，确认焦点与选中文字仍与取词时一致，再粘贴译文；选区变化、窗口关闭或焦点转到其他软件时会拒绝替换。可在原软件中按 `Ctrl+Z` 撤销。目标软件必须支持编辑与粘贴；只读文档或权限更高的软件可手动复制译文使用。

### 3.3 截图 OCR（Windows 10/11）

1. 在 TransPortal 设置的 **Screenshot OCR** 分区选择 **Windows OCR** 或 **ONNX · PP-OCRv4 FP32**。ONNX 使用中英混合模型；Windows OCR 可选择已安装的语言包，默认跟随 Windows 语言偏好。
2. 按 `Alt+Shift+S`（或点击浮层的 **提取文字**）。屏幕立即出现极速框选层，拖动框选文字后松开鼠标。TransPortal 在本机识别，自动把文字复制到剪贴板，并默认展开识别结果。可修正文字后再次点击 **复制**，或点击 **翻译**。
3. 按 `Alt+S`（或点击 **截图翻译**）框选文字，则识别后用当前翻译引擎逐块翻译，在截图原文字位置绘制译文，并在下方同步展开识别与译文段落。可切换 **查看原图 / 查看译图**、按 **100% 大小** 查看细节，或 **复制译图 / 保存译图**。
4. 框选或识别时按 `Esc` 取消。未识别到文字、语言包缺失、桌面捕获失败时，浮层会给出原因与重试入口。

纯 OCR 不访问词典或翻译服务；截图翻译会把识别文字交给所选翻译服务。纯 OCR 会把识别文字写入剪贴板；如果识别期间你复制了其它内容，会保留新内容并提示手动复制。截图图片只保留在内存中，点击 **保存译图** 后才写入选定文件。

如果更习惯 Windows 自带的截图界面，可在设置中把某个 OCR 快捷键改为 `Win+Shift+S`。这时 TransPortal 只观察该系统快捷键并等待截图工具复制到剪贴板的图片，需要在截图工具中开启 **自动复制到剪贴板**，且弹出会比内置框选慢。

使用 Windows OCR 时，中文截图可在系统 **时间和语言 → 语言和区域** 中安装中文 OCR 功能，然后在 TransPortal 的 OCR 设置中刷新并选择中文。自动选项按系统语言偏好选择识别器，不是自动检测图片语言。

ONNX 无需系统语言包。桌面安装包已附带模型；开发环境或资源损坏时，点击 **安装并启用 ONNX** 下载并校验资源，之后可离线识别。引擎选择在重启后恢复；切换失败会保留原引擎并显示原因。

浮层空态的 **打开图片** 可识别本地 PNG、JPEG、BMP、WebP 或 TIFF。macOS/Linux 当前使用此入口，尚未提供系统框选。识别完成后点击 **原位翻译** 生成译图；**校对文字** 可逐块修正 OCR 结果，再选择目标语言重新翻译。

图片回填使用文字块周围的颜色覆盖原字，并根据可用空间缩放、换行。复杂纹理、倾斜文字和很小的文字块可能留下色块或较小字号；展开 **校对文字 / 查看文字** 可读取完整原文、译文。某段翻译失败时保留该段原文，并显示错误。

### 3.4 持续自动翻译屏幕区域

1. 在浮层空态选择刷新间隔和目标语言，点击 **自动区域翻译**。
2. 在屏幕上拖动框选区域，松开鼠标后开始监控；框选时 `Esc` 取消。
3. 内容变化时自动重新识别并更新译图。窗口不会因失焦隐藏，可在原软件中继续滚动或输入；程序会排除自身窗口，避免识别自己的译文。
4. **暂停 / 继续** 控制监控，**重新选区** 更换区域，**停止** 或 `Esc` 停止并保留最后一帧供查看、导出，右上角关闭会释放结果。

自动模式目前需要 Windows 10 2004 或更新版本。刷新间隔是在上一轮识别、翻译结束后的等待时间；同一时间只处理一轮，未变化的图片不会重复翻译。网络失败会提示并重试。启动时使用当前翻译服务与目标语言，修改后请重新选区启动。不会保存选区或在重启后自动开始监控。

完整说明、诊断命令与 ONNX 资源信息见 [OCR.md](OCR.md)。

## 4. 幽灵伴读气泡（句子模式）

用于快速阅读句子译文，界面紧凑、可拖拽移动。

- 顶部圆点：绿色表示空闲，青色闪烁表示正在流式翻译。
- **复制**：点击复制图标，复制当前译文。
- **展开为词卡**：点击 `⤢` 图标，气泡平滑形变为完整词卡（FLIP 形变）。
- **拖动**：按住标题区域拖动窗口。

## 5. 深度词卡（单词模式）

词卡先由**本地 redb 词库**在毫秒级直出音标与释义，随后异步请求大模型补充地道语境例句。

### 5.1 卡片内容

- 单词 / 音标 / 发音按钮
- 词性标签（`n.` `v.` `adj.` 等）与释义
- 词形变化（exchange）
- 考试标签（CET4/6、IELTS、TOEFL、GRE 等）
- 语境例句（英文 + 中文对照）

### 5.2 操作按钮

| 按钮 | 功能 |
| --- | --- |
| 🔊 喇叭 | 播放发音（优先有道在线音频，失败则用系统 TTS） |
| ⚡ Anki | 将当前单词、音标与原句推送到 Anki 指定牌组（Rust 侧直连 AnkiConnect） |
| ⬇ 下载 | 导出 TSV 文件（可手动导入 Anki） |
| 📌 图钉 | 固定窗口：固定后点击外部不再自动隐藏（再点取消） |
| ⊟ 最小化 | 词卡折叠回幽灵气泡 |
| ← / → | 历史导航：后退 / 前进 |

### 5.3 例句交互式分词与无限下钻

- 例句中每个单词在**悬停**时高亮。
- **点击任意生词**：词卡原地切换为该词的解释。
- 前端维护**历史导航栈**，可用 `←` 返回到上一个母词，`→` 前进。
- 若配置了 OpenAI 兼容引擎，词卡会自动异步补充 LLM 生成的地道例句。

## 6. 设置窗口

点击气泡右上角 **齿轮图标**，会打开一个**独立的设置窗口**（不占用查词气泡的空间）：

- 设置窗口是普通窗口，可拖动、可调整大小、可通过标题栏关闭；
- 关闭设置窗口只是隐藏它，再次点击齿轮即可秒开；
- 设置窗口不会像气泡那样在失焦时自动隐藏；
- 所有设置**自动保存并在重启后恢复**（Provider、词典来源与顺序、快捷键、开机自启）。

设置内容包括 **Translation Provider**、**Global Shortcut**、**Startup** 与 **Dictionary**。

### 6.1 Provider 引擎

| 引擎 | 说明 | 是否需要 Key |
| --- | --- | --- |
| Google Free | 免 Key 公共接口，开箱即用 | 否 |
| OpenAI Compatible | 支持任意 OpenAI 兼容接口，SSE 流式输出 | 是 |

选择 `OpenAI Compatible` 后需填写：

- **Base URL**：如 `https://api.openai.com/v1`（兼容第三方网关）
- **API Key**：以 `sk-...` 开头的密钥
- **Model**：如 `gpt-4o-mini`

### 6.2 Global Shortcut（全局快捷键）

在 **Global Shortcut** 分区点击 Capture 输入框，直接按下想要的组合键即可（例如 `Alt+Q`、`Ctrl+Shift+D`）。至少需要一个修饰键（`Fn` 功能键除外）。设置立即生效并持久化，重启后保持。

### 6.3 Startup（开机自启）

勾选 **Launch TransPortal on system startup** 即可随系统启动。状态来自系统本身，重启后依旧反映真实值。

## 7. Anki 生词同步

### 7.1 前置准备

1. 安装并打开桌面版 **Anki**。
2. 安装 **AnkiConnect** 插件（代码 `2055492159`）。
3. 保持 Anki 运行，AnkiConnect 默认监听 `http://127.0.0.1:8765`。

### 7.2 同步操作

1. 打开任意单词的深度词卡。
2. 点击 `⚡ Anki`。
3. 成功后提示 `Card added to <牌组>!`；

同步内容包含：单词、音标、释义，以及**划词时的原上下文原句**，标签为 `TransPortal`、`AutoSynced`。

- 默认牌组：`Default`，笔记类型：`Basic`。
- 若 Anki 未运行，会提示 `Cannot reach AnkiConnect (ensure Anki is running on port 8765)`。
- 也可点击 `⬇` 导出 `单词_anki.tsv` 手动导入。

## 8. 查词来源（全部可配置）

在设置面板的 **Dictionary Sources** 分区，所有查词来源都以**有序、可开关的选项**呈现，可自由启用、禁用和调整顺序：

| 来源 | 类型 | 提供内容 | 默认 |
| --- | --- | --- | --- |
| Youdao | 在线 | 中文释义、词性、音标、音频、双语例句 | 启用（首选） |
| Google | 在线 | 中文释义、词性（`dt=bd` 词典通道） | 启用 |
| Local ECCEDICT | 本地 | 离线释义、词性、考试标签、词形 | 启用（需导入） |

- 勾选框：启用 / 停用某个来源；
- `▲` / `▼`：调整查询顺序（自上而下依次尝试，命中即返回）；
- 在线来源免 Key、开箱即用；本地来源未导入时显示 `not installed` 并自动跳过；
- 词卡会标注命中的来源（`youdao` / `google` / `local_eccedict`）。

### 8.1 安装本地 ECCEDICT（可选）

1. 点击 **Import CSV**，选择本地 [ECCEDICT](https://github.com/H1DDENADM1N/ECCEDICT)/[ECDICT](https://github.com/skywind3000/ECDICT) 的 `ecdict.csv`；
2. 或点击 **Download full** 一键下载完整 `ecdict.csv`（~63 MB，带进度）并导入。

本地词库存储在应用数据目录的 `transportal.redb`。把 `Local ECCEDICT` 拖到最上方即可实现亚毫秒本地直出。

### 8.2 富化 CSV（英美音标 + 考试标签）

ECCEDICT fork 的改进（**23.5 万条英美音标、1.25 万条标签**）只存在于 `output/phonetics.ddb`、`output/tag.ddb`（DuckDB），**没有写回 `ecdict.csv`**。用仓库自带脚本把它们合并成一个可直接导入的 CSV：

```bash
# 在 ECCEDICT 仓库目录下（已含 ecdict.csv 与 output/*.ddb）
uv run /path/to/TransPortal/scripts/eccedict/build_enriched_csv.py
# 产出 ecdict.enriched.csv，再用 Import CSV 导入
```

脚本读取 `ecdict.csv` 并与两个 `.ddb` 合并，写出同结构的 `ecdict.enriched.csv`（音标合并为 `英 /.../ 美 /.../`，标签刷新）。实测：77 万词条中富化 11.7 万音标、1.2 万标签。

> 词典来源的启用状态与顺序会自动保存并在重启后恢复。

## 9. 常见问题（FAQ）

**Q1：按 `Alt + T` 没有反应？**
- 确认应用仍在托盘运行；
- 检查快捷键是否被其他软件占用（如截图/输入法工具），可先退出冲突软件。
- 在设置中点击 **重新检测快捷键**，查看启动检查的具体结果。

**程序提示完整性检查失败时怎么办？**

Windows 发布版会在启动时比较程序文件与随安装包附带的 SHA-256。请从可信来源重新安装完整安装包，不要删除校验文件或用当前异常文件重新生成基准。设置中的 **程序完整性** 可查看正常程序的哈希值。这项检查不是病毒扫描，也不能代替发布者代码签名，详见 [启动检查说明](STARTUP_CHECKS.md)。

**Q2：读不到我选中的文字？**
- 部分控件不支持 UI Automation，系统会降级读取剪贴板。请先 `Ctrl+C` 复制，再按 `Alt + T`。
- 气泡中若出现错误提示，通常表示选区为空且剪贴板也为空。

**Q3：窗口没有毛玻璃 / 透明背景？**
- 透明效果依赖系统窗口合成，请确认系统已开启透明效果，且未在远程桌面/虚拟机等受限环境运行。

**Q4：点击 Anki 报错？**
- 依次确认：Anki 是否打开 → AnkiConnect 是否安装 → 端口 `8765` 是否被占用/修改。

**Q5：翻译结果为空或报网络错误？**
- 检查网络连接；`Google Free` 公共接口在部分网络下可能不稳定，可切换到 OpenAI 兼容引擎。

## 10. 键盘与交互速查

| 操作 | 方式 |
| --- | --- |
| 划词唤醒 | `Alt + T` |
| 截图提取文字并复制 | `Win + Shift + S`（Windows） |
| 截图翻译 | `Alt + S`（Windows） |
| 拖动气泡 | 按住顶部标题栏拖动 |
| 气泡 ⇄ 词卡 | 点击展开 / 最小化图标 |
| 例句下钻 | 点击例句中的单词 |
| 历史后退 / 前进 | 词卡左上角 `←` / `→` |
| 播放发音 | 词卡 🔊 按钮 |
| 固定窗口 | 词卡/气泡 📌 图钉 |
| 打开设置 | 气泡右上角 ⚙️（独立窗口） |
| 关闭设置 | 设置窗口标题栏关闭按钮（仅隐藏） |
| 隐藏气泡 | 点击窗口外 / `Esc` |
| 退出 | 托盘菜单 `Quit TransPortal` |

> 点击气泡窗口以外的任意位置，或按下 `Esc`，气泡会自动隐藏到托盘（幽灵模式）；再次按 `Alt + T` 即可唤醒。设置窗口不受此影响。
