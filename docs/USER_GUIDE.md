# TransPortal 用户操作文档

轻量传送门（TransPortal）是一款开源桌面翻译与词典协同工作台。它常驻托盘，通过全局快捷键随时捕获你在任意软件中选中的文本，并自动判断是"单词"还是"句子"，分别以**深度词卡**或**幽灵伴读气泡**呈现。

---

## 1. 运行环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11（原生划词）、macOS / Linux（仅剪贴板降级） |
| 网络 | 使用在线翻译 / AI 增强时需要联网 |

> 离线词典查询、音标释义、词卡形变等核心交互无需联网。

---

## 2. 启动与退出

1. 启动 TransPortal 后，主界面（幽灵气泡窗口）会出现在屏幕中央。
2. 关闭窗口不会退出程序，应用会**最小化到系统托盘**继续常驻。
3. 退出方式：
   - 右键 / 左键点击托盘图标 → `Quit TransPortal`；
   - 或在气泡右上角菜单中选择退出（依版本而定）。

托盘菜单项：

- `Show TransPortal`：显示气泡窗口
- `Hide to Tray`：隐藏到托盘
- `Quit TransPortal`：完全退出

## 3. 核心操作：全局划词

### 3.1 默认快捷键

| 快捷键 | 功能 | 说明 |
| --- | --- | --- |
| `Alt + Q` | 划词查询 | 捕获当前选中文本并唤醒词卡/气泡 |
| `Alt + Shift + X` | 截图对照翻译 | 框选屏幕长文，图文双栏对照并支持点词查词 |
| `Alt + S` | 原图直接翻译 | 框选屏幕文字，在原图文字位置覆盖译文 |
| `Alt + Shift + S` | 提取文字 | 框选屏幕文字，识别后自动复制到剪贴板 |
| `Ctrl + C + C` | 快捷翻译 | Windows 上 0.5 秒内按两次 C，翻译本次复制文字 |
| `Alt + Z` | 替换翻译 | 划选屏幕文字后原地静默极速覆盖译文 |
| `Alt + Space` | 输入翻译 | 呼出输入框即时输入并翻译 |
| `Alt + Shift + C` | 静默 OCR | 后台快速识别并复制文字，不弹出浮层 |

> 所有快捷键可在设置中自定义。截图不再调用 Windows 截图工具：按下快捷键后桌面立即冻结并出现框选层，松开鼠标即识别。

启动时若发现取词键或截图键注册失败，浮层会列出冲突键位。关闭占用它的软件后点击 **重新检测**；也可在设置的 **Global Shortcut** 分区查看状态或更换键位。注册失败会保留原有可用键位，不会把失败的选择保存为当前值。

### 3.2 使用步骤

1. 在任意应用（浏览器、PDF 阅读器、Office、IDE 等）中选中一段文字。
2. 按下 `Alt + Q`。
3. TransPortal 自动执行：
   - 优先通过 **UI Automation** 读取焦点控件的选区；
   - 若目标控件不支持，则向原窗口发送复制指令，确认剪贴板更新后读取；复制失败时提示重试。
4. 窗口在鼠标位置附近弹出，并自动分流：

| 选中内容 | 呈现方式 |
| --- | --- |
| 单个单词 / 短词组（≤ 2 词且无句末标点） | **深度词卡（Word Card）** |
| 句子 / 段落 | **幽灵伴读气泡（Ghost Bubble）** |

> 自动分流基于本地毫秒级启发式判断，词数、字符数与标点共同决定。

也可按住 `Ctrl`，在 0.5 秒内按两次 `C`；两次复制之间松开 Ctrl 也可以。长按 C 的键盘连发不会触发翻译。开关位于设置的 **Global Shortcut → Ctrl+C+C 翻译**，关闭后仍可正常复制。

要替换其他软件输入框中的原文，取词后点击结果卡的 **替换选中文字**。程序会回到原窗口，确认焦点与选中文字仍与取词时一致，再粘贴译文；选区变化、窗口关闭或焦点转到其他软件时会拒绝替换。可在原软件中按 `Ctrl+Z` 撤销。目标软件必须支持编辑与粘贴；只读文档或权限更高的软件可手动复制译文使用。

### 3.3 截图 OCR（Windows 10/11）

1. 在 TransPortal 设置的 **Screenshot OCR** 分区选择 **Windows OCR** 或 **ONNX · PP-OCRv5 FP32**。ONNX 使用中英混合模型；Windows OCR 可选择已安装的语言包，默认跟随 Windows 语言偏好。
2. 按 Alt+Shift+S（或点击浮层的 **静默 OCR**）：极速框选屏幕文字，松开鼠标后由本地引擎静默识别并直接写入系统剪贴板，后台极速运行，零视觉干扰。
3. 按 Alt+Shift+C（或点击 **截图搜索**）：框选文字提取后，根据当前语言偏好自动唤起系统默认浏览器通过百度/谷歌/必应或自定义搜索引擎进行搜索。
4. 按 Alt+Shift+X（或点击 **截图对照**）：框选屏幕区域，呈现原图与译文双栏对照卡片，支持长文句间分词与点击即刻查词。
5. 按 Alt+S（或点击 **原图翻译**）：框选屏幕图像，识别后用当前翻译引擎逐块翻译，在截图原文字位置覆写呈现译文，可在下方同步校对与切换原图/译图（快捷键 Tab）。
6. 框选或识别时按 Esc 取消。未识别到文字、语言包缺失、桌面捕获失败时，浮层会给出原因与重试入口。

纯 OCR 不访问词典或翻译服务；截图翻译会把识别文字交给所选翻译服务。纯 OCR 会把识别文字写入剪贴板；如果识别期间你复制了其它内容，会保留新内容并提示手动复制。截图图片只保留在内存中，点击 **保存译图** 后才写入选定文件。

如果更习惯 Windows 自带的截图界面，可在设置中把某个 OCR 快捷键改为 `Win+Shift+S`。这时 TransPortal 只观察该系统快捷键并等待截图工具复制到剪贴板的图片，需要在截图工具中开启 **自动复制到剪贴板**，且弹出会比内置框选慢。

使用 Windows OCR 时，中文截图可在系统 **时间和语言 → 语言和区域** 中安装中文 OCR 功能，然后在 TransPortal 的 OCR 设置中刷新并选择中文。自动选项按系统语言偏好选择识别器，不是自动检测图片语言。

ONNX 无需系统语言包。桌面安装包已附带模型；开发环境或资源损坏时，点击 **安装并启用 ONNX** 下载并校验资源，之后可离线识别。引擎选择在重启后恢复；切换失败会保留原引擎并显示原因。

浮层空态的 **打开图片** 可识别本地 PNG、JPEG、BMP、WebP 或 TIFF。macOS/Linux 当前使用此入口，尚未提供系统框选。识别完成后点击 **原位翻译** 生成译图；**校对文字** 可逐块修正 OCR 结果，再选择目标语言重新翻译。

图片回填使用文字块周围的颜色覆盖原字，并根据可用空间缩放、换行。复杂纹理、倾斜文字和很小的文字块可能留下色块或较小字号；展开 **校对文字 / 查看文字** 可读取完整原文、译文。某段翻译失败时保留该段原文，并显示错误。

### 3.4 持续自动翻译屏幕区域

1. 在浮层空态选择刷新间隔和目标语言，点击 **自动区域翻译**。
2. 在屏幕上拖动框选区域，松开鼠标后开始监控；框选时 `Esc` 取消。
3. 内容变化时自动重新识别并更新译图。窗口不会因失焦隐藏，可在原软件中继续滚动或输入；程序会排除自身窗口，避免识别自己的译文。
4. **暂停 / 继续** 控制监控，**重新选区** 更换区域，**停止** 或 `Esc` 停止并保留最后一帧供查看、导出，右上角关闭会释放结果。

自动模式目前需要 Windows 10 2004 或更新版本。刷新间隔是在上一轮识别、翻译结束后的等待时间；同一时间只处理一轮，未变化的图片不会重复翻译。网络失败会提示并重试。启动时使用当前翻译服务与目标语言，修改后请重新选区启动。不会保存选区或在重启后自动开始监控。

完整说明、诊断命令与 ONNX 资源信息见 [OCR.md](OCR.md)。

## 4. 幽灵伴读气泡（句子模式）

用于快速阅读句子译文，界面紧凑、可拖拽移动。

- 顶部圆点：绿色表示空闲，青色闪烁表示正在流式翻译。
- **复制**：点击复制图标，复制当前译文。
- **展开为词卡**：点击 `⤢` 图标，气泡平滑形变为完整词卡（FLIP 形变）。
- **拖动**：按住标题区域拖动窗口。

## 5. 深度词卡（单词模式）

词卡先由**本地 redb 词库**在毫秒级直出音标与释义，随后异步请求大模型补充地道语境例句。

### 5.1 卡片内容

- 单词 / 音标 / 发音按钮
- 词性标签（`n.` `v.` `adj.` 等）与释义
- 词形变化（exchange）
- 考试标签（CET4/6、IELTS、TOEFL、GRE 等）
- 语境例句（英文 + 中文对照）

### 5.2 操作按钮

| 按钮 | 功能 |
| --- | --- |
| 🔊 喇叭 | 播放发音（优先有道在线音频，失败则用系统 TTS） |
| ⬇ 下载 | 导出 TSV 文件（包含单词、音标、释义与原句上下文） |
| 📌 图钉 | 固定窗口：固定后点击外部不再自动隐藏（再点取消） |
| ⊟ 最小化 | 词卡折叠回幽灵气泡 |
| ← / → | 历史导航：后退 / 前进 |

### 5.3 例句交互式分词与无限下钻

- 例句中每个单词在**悬停**时高亮。
- **点击任意生词**：词卡原地切换为该词的解释。
- 前端维护**历史导航栈**，可用 `←` 返回到上一个母词，`→` 前进。
- 若配置了 OpenAI 兼容引擎，词卡会自动异步补充 LLM 生成的地道例句。

### 5.4 明确收录一个用法

英语单词词卡的释义下方新增 **记住这个用法**：

1. 正常查词即可，只有点击此入口才展开收录表单，普通查词不会自动加入收藏。
2. 选择要记的一个释义。系统不会把这个词的全部释义合成一条学习记录。
3. 选择词卡已有的例句，或选择 **不保存例句**。默认使用已有的第一条例句，不会额外读取其他应用的文字、窗口标题或截图。
4. 点击 **收录用法**，看到 **已收录** 后即可关闭词卡、继续阅读。

例句会标明来自词典、已有 AI 生成例句或已有点词原句。未命中词典时，允许明确确认后保存翻译结果，但会标注为“翻译结果”，不会冒充词典释义。

相同单词、词性、释义会去重，并保留最初的例句和收录时间。若原记录没有例句或音标，后续明确收录可以补齐缺失项。不同义项分别保存；当前阶段没有自动复习、评分或提醒。

## 6. 设置窗口

点击气泡右上角 **齿轮图标**，会打开一个**独立的设置窗口**（不占用查词气泡的空间）：

- 设置窗口是普通窗口，可拖动、可调整大小、可通过标题栏关闭；
- 关闭设置窗口只是隐藏它，再次点击齿轮即可秒开；
- 设置窗口不会像气泡那样在失焦时自动隐藏；
- 所有设置**自动保存并在重启后恢复**（Provider、词典来源与顺序、快捷键、开机自启）。

设置内容涵盖 **Appearance 外观与界面**、**Translation Provider 翻译引擎**、**Screenshot OCR 识别引擎**、**Global Shortcut 全局快捷键**、**Clipboard 剪贴板监听**、**Startup 开机自启与完整性**、以及 **Dictionary Sources 查词来源**。

### 6.1 Provider 引擎与目标语言

| 引擎 | 说明 | 是否需要 Key |
| --- | --- | --- |
| Youdao Free | 有道免费公共查词与翻译接口，中文互译效果极佳，开箱即用 | 否 |
| Google Free | 谷歌免费公共翻译接口，多语种支持广泛，开箱即用 | 否 |
| Tencent Free | 腾讯交互翻译免费公共接口，开箱即用 | 否 |
| OpenAI Compatible | 支持任意 OpenAI 兼容大模型（DeepSeek、GPT、Claude 代理等），SSE 流式输出 | 是 |

选择 `OpenAI Compatible` 后需填写：

- **Base URL**：如 `https://api.openai.com/v1`（兼容第三方网关或本地 Ollama）
- **API Key**：API 访问密钥
- **Model**：如 `gpt-4o-mini` 或 `deepseek-chat`
- **Temperature & Prompt Template**：可自定义温度与提示词风格（直译 / 学术 / 编程 / 随意）

### 6.2 Appearance（外观与界面）

- **主题模式**：跟随系统、浅色模式、深色模式。
- **浮层透明度**：25% ~ 100% 任意平滑调节，半透明 HUD 悬浮风格。
- **字号大小**：12px ~ 20px 动态字号适配。
- **平滑进出过渡动效**：120ms 微弹簧展开与淡出，消除首帧闪烁。
- **截图十字对齐辅助线**：在截图框选时显示 1px 细对齐参考线。

### 6.3 Global Shortcut（全局快捷键与手势）

在 **Global Shortcut** 分区点击对应动作的输入框，按下想要的按键组合即可自定义（如 `Alt+Q`、`Alt+S`）。至少需要一个修饰键（`Fn` 除外），设置立即生效并持久化。

- **快捷翻译 (Ctrl+C+C)**：500ms 内连按两次 C 触发查词，不影响普通复制。
- **墨水修饰键 (Ink Key)**：可选 `Ctrl`、`Alt`、`Shift` 或 `CapsLock`，划选文字后按下修饰键即查词。
- **剪贴板监听**：开启后，任何应用复制文本均会自动同步翻译。

### 6.4 Startup（开机自启与完整性）

- **开机自启**：勾选 **Launch TransPortal on system startup** 即可随系统启动。
- **程序完整性**：查看当前执行文件的 SHA-256 签名校验基准，防止程序被非法篡改。

### 6.5 生词收藏：查看、删除与导出

设置窗口左侧选择 **生词收藏**，可搜索单词、释义或例句，并分页查看已保存的用法。点击某条记录的删除图标、确认后，会一并删除该用法及其例句。

- **导出全部 JSON**：保存完整用法、例句来源、音标与时间戳，供备份使用。当前版本暂未提供备份导入界面。
- **导出全部 TSV**：供表格工具或 Anki 导入。前四列为 `Word / Phonetic / Definition / Context`，其余列包含词性、词形、例句译文与来源信息；导入时按需映射，跳过表头行。
- 导出始终包含全部收藏，而非当前搜索结果或当前页。请选择一个新文件，已有文件不会被覆盖。

收藏仅存放在应用数据目录下独立的 `learning.redb` 中，与可重新下载的词典文件分离，重启或重置偏好设置不会清空收藏。数据库异常或版本不兼容时会提示错误，不会自动重建并丢弃原有学习数据。普通查词不会创建收藏记录。

## 7. 生词卡片导出 (TSV)

在任意单词的深度词卡中，点击右上角 `⬇`（Export TSV）按钮：

1. 即可下载并保存 `单词_vocabulary.tsv` 文件。
2. 导出内容包含：单词、音标、释义，以及**划词时的原上下文原句**。
3. 可直接在 Excel 中查看，或手动导入各类生词本应用及 Anki。

## 8. 查词来源（全部可配置）

在设置面板的 **Dictionary Sources** 分区，所有查词来源都以**有序、可开关的选项**呈现，可自由启用、禁用和调整顺序：

| 来源 | 类型 | 提供内容 | 默认 |
| --- | --- | --- | --- |
| Youdao | 在线 | 中文释义、词性、音标、音频、双语例句 | 启用（首选） |
| Google | 在线 | 中文释义、词性（`dt=bd` 词典通道） | 启用 |
| Local ECCEDICT | 本地 | 离线释义、词性、考试标签、词形 | 启用（需导入） |

- 勾选框：启用 / 停用某个来源；
- `▲` / `▼`：调整主要查询来源的顺序（本地优先时仍直接离线返回）；
- 在线来源免 Key、开箱即用；本地来源未导入时显示 `not installed` 并自动跳过；
- 词卡会标注命中的来源（`youdao` / `google` / `local_eccedict`）。

### 8.1 安装本地 ECCEDICT（可选）

1. 推荐点击 **下载并导入富化 ECCEDICT**。程序经 GHProxy 优先、直连/CDN 后备下载固定版本的完整基础 CSV（约 63 MB），校验长度和 SHA-256 后，在 Rust 中合并随应用附带的增强数据，再导入 `redb`。
2. 也可点击 **导入 CSV 词库**，选择自己的 `ecdict.enriched.csv`、普通 ECDICT 或兼容格式 CSV；手动导入不会强行覆盖用户选择的字段。

本地词库存储在应用数据目录的 `transportal.redb`。已有旧词库需要点击一次富化下载更新，不会自动后台替换；该操作不影响独立的 `learning.redb` 生词收藏。设置中显示增强版本和音标/标签覆盖数量。

### 8.2 富化 CSV（英美音标 + 考试标签）

ECCEDICT fork 的英美音标和考试标签增强数据在 `output/phonetics.ddb`、`output/tag.ddb` 中，不在默认的基础 `ecdict.csv` 中。TransPortal 将固定版本的增强数据预转换为压缩 CSV 随应用附带；**用户端不需要 Python 或 DuckDB**。

- 音标按 `英 /.../ 美 /.../` 展示，未命中的词保留原音标。
- 标签与基础词库的原有标签取并集、去重，不会用新增标签覆盖掉旧标签。
- 原有中文/英文释义、词形、例句、柯林斯星级、牛津核心词及词频字段保留；星级、核心词与词频现已可在词卡查看。
- 词频和考试标签是来源数据的参考，不代表实时词频或最新年度的官方考试大纲。
- 增强数据库的总行数不等于基础 CSV 中能匹配的行数，实际覆盖以导入后设置显示为准。

### 8.3 在线查询与本地数据合并

保留默认的 **有道 → Google → 本地 ECCEDICT** 顺序即可：在线查词命中后，只要本地词典已安装且启用，程序会利用本地 `redb` 补充数据，不会再请求其他在线词典。

- 在线词头、主释义、例句、发音音频保持原样。
- 本地英美双音标可补足在线缺失或仅单音标的数据；已有在线双音标保持优先。
- 标签去重合并；补充缺失的规范词形、星级、核心词标记及词频。
- 本地不同释义、英文释义和例句位于独立的可展开“本地 ECCEDICT 的释义与例句”区域，不混成在线主释义。
- 词卡标明主要来源与本地补充。收录本地补充释义时，生词收藏仍记录为本地词典来源。
- 对经词典词形确认的变体，可以展示其原形的标签等信息，但不会把原形音标冒充为变体的音标。
- 禁用本地词典会关闭补充并清除查询缓存；未安装或本地补充失败时，在线查词仍可使用。

若把 `Local ECCEDICT` 调到第一位，本地命中仍直接离线返回，不为合并而额外请求在线服务。

### 8.4 开发者：重建增强数据

开发时才需要用 `uv` 和 DuckDB 从固定的上游输入重建资源：

```bash
# 在 TransPortal 仓库根目录运行
uv run scripts/eccedict/build_enriched_csv.py --download \
  --cache-dir /tmp/opencode/eccedict \
  --out /tmp/opencode/eccedict/ecdict.enriched.csv \
  --overrides-out src-tauri/resources/dictionary/enrichment.csv.gz \
  --manifest-out src-tauri/resources/dictionary/manifest.json
```

脚本校验固定版本的 Git blob，生成同结构的完整 `ecdict.enriched.csv`、可复现压缩增强资源及 SHA-256 清单。资源直接编译进 Rust，不会进入前端 JavaScript，也不需要另建数据服务。

> 词典来源的启用状态与顺序会自动保存并在重启后恢复。

## 9. 常见问题（FAQ）

**Q1：按 `Alt + Q` 没有反应？**
- 确认应用仍在托盘运行；
- 检查快捷键是否被其他软件占用（如截图/输入法工具），可先退出冲突软件。
- 在设置中点击 **重新检测快捷键**，查看启动检查的具体结果。

**程序提示完整性检查失败时怎么办？**

Windows 发布版会在启动时比较程序文件与随安装包附带的 SHA-256。请从可信来源重新安装完整安装包，不要删除校验文件或用当前异常文件重新生成基准。设置中的 **程序完整性** 可查看正常程序的哈希值。这项检查不是病毒扫描，也不能代替发布者代码签名，详见 [启动检查说明](STARTUP_CHECKS.md)。

**Q2：读不到我选中的文字？**
- 部分控件不支持 UI Automation，系统会降级读取剪贴板。请先 `Ctrl+C` 复制，再按 `Alt + Q`。
- 气泡中若出现错误提示，通常表示选区为空且剪贴板也为空。

**Q3：窗口没有半透明背景？**
- 半透明 HUD 效果依赖系统窗口合成，请确认系统已开启透明效果，且未在远程桌面/虚拟机等受限环境运行。

**Q4：翻译结果为空或报网络错误？**
- 检查网络连接；若公共接口遇到网络波动，可切换到其他免费引擎或 OpenAI 兼容引擎。
